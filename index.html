CẤU TRÚC RẼ NHÁNH IF

Yêu cầu cần đạt

  • Phân tích và giải thích được vai trò của các phép toán logic trong việc hình thành biểu thức điều kiện.
  • Thiết kế và kiểm thử được chương trình Python sử dụng lệnh rẽ nhánh if để giải quyết bài toán thực tiễn.

Tìm hiểu biểu thức logic

Biểu thức logic trong Python là nền tảng để đưa ra quyết định. Nó luôn trả về một trong hai kết quả thuộc kiểu dữ liệu bool:

True (Đúng) False (Sai)
# Ví dụ Python
> print(5 > 3)
True
> print(10 == 2)
False

Các phép toán so sánh

Nhỏ hơn <
Lớn hơn >
Nhỏ hơn / Bằng <=
Lớn hơn / Bằng >=
Bằng nhau ==
Khác nhau !=

Các phép toán kết hợp

and

Chỉ trả về True khi tất cả các điều kiện thành phần đều đúng.

or

Trả về True nếu có ít nhất một điều kiện thành phần đúng.

not

Dùng để đảo ngược giá trị logic (True thành False và ngược lại).

Cấu trúc lệnh rẽ nhánh

Dạng thiếu (if)

Nếu điều kiện đúng, chương trình thực hiện khối lệnh bên trong. Nếu sai, chương trình bỏ qua khối lệnh đó và đi tiếp.

if <điều_kiện>:
    # Khối lệnh được thụt lề
    print("Điều kiện đúng!")

Dạng đủ (if...else)

Nếu điều kiện đúng thực hiện khối lệnh 1. Ngược lại (nếu điều kiện sai) thì sẽ thực hiện khối lệnh 2.

if <điều_kiện>:
    # Khối lệnh 1
else:
    # Khối lệnh 2

Lưu ý cú pháp cực kỳ quan trọng:

  • Từ khóa if và else phải viết thẳng hàng với nhau.
  • Bắt buộc phải có dấu hai chấm (:) sau biểu thức điều kiện và sau từ khóa else.
  • Khối lệnh bên trong phải được thụt lề nhất quán (dùng phím Tab hoặc 4 khoảng trắng). Nếu không Python sẽ báo lỗi IndentationError.
